**Install:** download `Nib-v2.6.0.apk` below and open it on your tablet or phone. It updates 2.x in place, and your notebooks stay.

**Restructured folders & collapsible sidebar**
- Top-level folders now appear directly on **Home** alongside unfiled notebooks, with a dedicated **All notes** view and pinned folders shown in **Favourites**.
- Personalise folders with a 10-colour palette, pin important folders to the top, nest subfolders, navigate with clickable breadcrumbs or the Back button, and choose whether deleting a folder keeps its notes or moves them to Trash.
- Moving notes is faster from anywhere: tap **⋮ → Move** on any notebook card, pull existing notes directly from inside a folder (**Move notebooks here**), or enter **Select** mode and tap a highlighted folder card to drop selected notebooks straight into it.
- Export an entire folder (including subfolders) as PDFs in one step, and keep folder colours and pinned states across library backups and restores.
- The sidebar toggle button now also appears on tablets so you can collapse or expand the left sidebar whenever you want more space for your notebooks.

**Office document import, scanning & save-first exports**
- Improved offline **DOCX** and **PPTX** import (plus TXT and Markdown): preserves page dimensions and orientation, slide/layout/master backgrounds (solid, gradient, image, and theme fills), tables, embedded images, bullet and Wingdings/Symbol glyphs, inline formatting, and non-Latin scripts.
- Exporting notebooks, single pages, PNG images, `.nib` archives, or batch/folder PDFs now opens Android's **Files** picker (or folder picker for multi-file exports) so you can save directly first, while **Share PDF…** remains available when you want to send straight to another app.
- Theme-aware **progress popups** now show live status during document, PDF, photo, and backup imports, camera scans, PDF/`.nib` exports, notebook duplication, and library backups.

**Pages & editor**
- Added a subtle gap between continuous pages so page breaks are immediately clear while scrolling and writing.
- The **Pages** overview now previews each page in its true portrait or landscape aspect ratio without adding extra white margins.
- Tap the top-left page and zoom indicator to open **Jump to page** and go straight to any page number (with a quick **Reset zoom** action when zoomed).
- **Hide tools while writing** is now turned off by default so floating toolbars stay visible unless you enable auto-hide in settings.

**Fixes**
- Creating or importing a notebook while inside a folder now keeps it inside that folder instead of placing it on Home.
- Batch and folder PDF exports now generate unique filenames when multiple notebooks share the same title.
- Hardened DOCX PDF rendering against resource leaks on failed conversions.

**Xiaomi HyperOS + root (optional):** `nib-stylus-unblock.zip` is built and attached alongside the APK for releases. It only removes HyperOS's pen-stroke delay for Nib. See [magisk-stylus-unblock](../../magisk-stylus-unblock/README.md).
